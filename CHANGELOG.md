# Changelog

## 0.1.0-dev

- Added the initial `archive` application crate and `archive_tests` tooling crate.
- Added format-neutral archive model, command model, settings facade, localization facade, and snapshot surfaces.
- Added TAR, TAR.GZ, gzip, ZIP stored, and ZIP DEFLATE read/write foundations.
- Added extraction, verification, preview, stale-event, queue, source-monitoring, and temporary-resource tests.
- Added Ada `check_all`, fixture manifest validation, release-report smoke tooling, and CI delegation.
